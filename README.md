# Campus Loop

initial Next.js App Router project structure.

```text
app/
├── page.tsx
├── layout.tsx
├── listing/[id]/page.tsx
├── create/page.tsx
├── requests/page.tsx
├── profile/[id]/page.tsx
├── admin/page.tsx
└── api/
components/
├── ListingCard.tsx
├── SearchBar.tsx
├── FilterBar.tsx
├── RequestButton.tsx
├── StatusBadge.tsx
└── Navbar.tsx
lib/
└── supabase/
types/
└── database.ts
```
